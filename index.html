Slide 05 / 05

Architecture, roles and KPIs

Production-grade engineering built for enterprise scale

Architecture

Frontend React 19, TypeScript, Tailwind, React Flow, Recharts
Backend FastAPI, SQLAlchemy, Alembic, WebSockets for live events
AI Engine LangGraph agents, HDBSCAN, anomaly detection, VADER, NetworkX
Data MySQL 8 with automatic SQLite fallback

Outcome KPIs

  • Time to detect and resolve

    Faster automated root-cause detection & triaging

  • Complaint rate, affected segment

    Targeted cohort relief before viral churn

  • Revenue at risk recovered

    High-LTV accounts proactively protected

  • CSAT and sentiment recovery

    Verified post-intervention positive sentiment lift

  • Case re-open rate

    Strict closed-loop telemetry prevents false closures

Role-based access

VIEWER
Read-only live dashboards, metric telemetry & recovery audits
ANALYST
Inspects causal graphs, injects evidence & tunes thresholds
APPROVER

ADMIN
Enterprise connector security, policy guardrails & user management
